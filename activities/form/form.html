Engagement - Form

The form tag has an "action" attribute. What does it do?

The "action" attribute specifies where to send the form-data when a form is submitted.

The form tag has a "method" attribute. What does it do?

The "method" attribute specifies the HTTP method (GET or POST) to be used when sending form-data.

What is the difference between a "POST" and a "GET"?

GET requests data from a specified resource, while POST submits data to be processed to a specified resource.

What is the difference between "padding" and "margin"?

Engagement - Form Processing with JavaScript

What is JavaScript? How did it get its name?

JavaScript is a programming language that enables interactive web pages. It was originally named Mocha, then LiveScript, and finally JavaScript.

What are the two ways you can run JavaScript?

JavaScript can be run in the browser or on the server, specifically in the DOM and Node.js (Express.js).

What was the most popular front-end js library?

jQuery was the most popular front-end js library.

What is the most popular front-end js library today?

React is the most popular front-end js library today.

Engagement - Form Processing with AJAX

What is AJAX?

AJAX is a technique for creating fast and dynamic web pages. It allows web pages to be updated asynchronously by exchanging small amounts of data with the server behind the scenes.

Why do you put your JS Code in a separate file?

Putting JS code in a separate file allows for better organization and easier maintenance. It also allows for better performance and caching.
