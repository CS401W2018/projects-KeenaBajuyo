Questions:

Why is the viewport meta tag important?

The viewport meta tag is vital to ensure that a web page is accurately measured on various devices, aiming to give users a greater experience on mobile or desktop screens.

How can you adjust the CSS for printing?

We can adjust the CSS for printing by utilizing a different stylesheet with the media="print" attribute to define styles specifically for print layouts.

When would you want to adjust the CSS for printing?

We would want to modify the CSS for printing when we need to make sure that our webpage is formatted accurately for printing, as this provides a neater and more readable layout without including unnecessary elements like navigation bars or background images.

Questions pt. 2:

Why do we need a viewport meta tag?

I believe we need the viewport meta tag because it allows web pages to adjust their layout and scale to fit the screen size on a device, providing a better user experience on mobile devices.

When you select the same tag twice, and in one of them you say "flex-direction: column;" and the other says "flex-direction: row;", which one takes priority?

Generally, the browser applies the CSS rule that comes later in the stylesheet, so the last one will take priority.

How do you change the CSS for a web page displayed on a phone?

I use a media query in my CSS code to adjust in to a phone, like: "@media only screen and (max-width: 900px)". This allows me to apply specific styles when the screen width is 900 pixels or less.
