Engagement - Tables

Questions:

When do you use a table?

You use a table when you have data or when players need information about schedules or statistics. It can also be used for class schedules.

When do you not use a table?

You don't use a table to layout elements on your page. Positioning things on your page using tables can cause confusion for search engines like Google.

When do you need to do extra work for table accessibility?

You need to do extra work for table accessibility when you use:

  • thead: First row (labels)
  • tbody: Data
  • tfoot: Averages, totals, summary of data
